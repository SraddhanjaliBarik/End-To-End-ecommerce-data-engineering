# End-To-End-ecommerce-data-engineering
Built an end-to-end Ecommerce Data Analytics solution using Microsoft Fabric implementing a Medallion architecture (Bronze, Silver, Gold) within a Lakehouse environment for scalable and structured data processing.
The Bronze layer was implemented using Dataflow, where raw ecommerce data was ingested from multiple sources and stored in a structured format for downstream processing. The Silver and Gold layers were developed using Fabric Notebooks, where data cleansing, transformation, and business-level aggregations were performed to prepare analytics-ready datasets. A fully orchestrated pipeline scheduling mechanism was implemented to automate data ingestion and transformation workflows, ensuring timely and consistent data refresh across all layers.
Finally, an interactive Power BI dashboard was built on top of the Gold layer to visualize key ecommerce KPIs such as total order amount by gender, payment method, and location, along with counts of order ID, customer ID, and ticket ID to analyze revenue distribution, customer behaviors, enabling actionable business insights.
The solution ensures data reliability, scalability, and governance through Microsoft Fabric’s integrated monitoring and Lakehouse architecture.
